Breeze / Model Context Protocol

MCP server hujjati

Breeze tool’lariga Streamable HTTP orqali ulaning. MCP endpoint /mcp manzilida ishlaydi.

GET /health

Server ishlayotganini tekshirish uchun ochiq health endpoint. MCP endpoint esa JWT rejimida bearer token talab qiladi.

Ulanish

Client manzili: http://localhost:8000/mcp. Boshqa host yoki portdan foydalansangiz, manzilni moslang. Tashqi tarmoqda HTTPS reverse proxy ishlating.

from fastmcp import Client

async with Client("http://localhost:8000/mcp", auth="<JWT_TOKEN>") as client:
    tools = await client.list_tools()
    result = await client.call_tool("greet", {"name": "Ali"})
    print(result.data)

JWT tokenni slayd24-ai auth xizmatidan oling. FastMCP client uni Authorization: Bearer <token> sifatida yuboradi.

Namuna tool

greet(name: str) -> str

Berilgan ismga salom qaytaradi. Masalan, greet(name="Ali") natijasi Salom, Ali!
