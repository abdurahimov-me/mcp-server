Tool katalogi

Serverdagi tool va argumentlar avtomatik ko‘rsatiladi. Kerakli toolni qidiring, sxemasini ochib ko‘ring.

MCP endpoint /mcp
↗
Serverga ulanish

Streamable HTTP · JWT rejimida Bearer token talab qilinadi

Kod namunasini ko‘rish →
from fastmcp import Client

async with Client("https://your-host/mcp", auth="<JWT_TOKEN>") as client:
    tools = await client.list_tools()
    print([tool.name for tool in tools])
